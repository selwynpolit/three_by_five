# Keyboard Shortcuts

Once you know these, 3by5 gets noticeably faster. Most of them are exactly what you'd guess — the ones that aren't are worth a quick scan.

---

## Global shortcuts

These work from anywhere in the app.

| Shortcut | What it does |
|----------|--------------|
| ⌘N | Create a new card |
| ⌘K | Open / close the global search overlay |
| ⌘? | Open / close the help panel |
| ⌘1 | Switch to Card View |
| ⌘2 | Switch to Kanban View |
| ⌘3 | Switch to Calendar View |
| ⌘4 | Switch to Today View |
| ⌘5 | Switch to Archive View |
| ⌘⇧B | Create Backup |
| ⌘⇧E | Export Data |
| ESC | Close the task detail panel (if one is open) |

---

## Task detail panel

The task detail panel has a few shortcuts worth knowing, especially for quick edits without reaching for the mouse.

| Shortcut | What it does |
|----------|--------------|
| ESC | Close the panel. If there's an unsaved note, you'll get a prompt first. |
| Enter (in the title field) | Save the title and close the panel |
| ⌘↵ (in description or note field) | Save and close the panel |

The distinction between Enter and ⌘↵ is intentional. In a rich text field you often want to press Enter to start a new line — ⌘↵ is the "I'm done" gesture that saves and closes.

## Global search overlay (⌘K)

| Shortcut | What it does |
|----------|--------------|
| Arrow Up / Arrow Down | Move through results |
| Enter | Open the selected result |
| ESC | Close the search overlay |

Results appear as you type, so you rarely need to finish a word before you find what you're looking for.

---

## Task List view

| Shortcut | What it does |
|----------|--------------|
| ESC (in the search field) | Clear the search and un-focus the field |

---

## Stack View (flip deck)

| Shortcut | What it does |
|----------|--------------|
| → (Arrow Right) | Flip to the next card (moves it to the discard pile) |
| ← (Arrow Left) | Go back to the previous card (returns it from the discard pile) |

You can also swipe left and right on your trackpad to flip cards — whichever feels more natural.

---

## Tips for getting shortcuts into muscle memory

You don't have to learn all of these at once. The three that will change your day fastest are:

1. **⌘K** — global search. Once you're used to it, you'll use it constantly.
2. **⌘1 through ⌘5** — switching views without touching the sidebar feels great.
3. **ESC** — closes panels and clears search fields. When in doubt, press ESC.

The rest tend to stick naturally as you use the app. Right-clicking things is also worth a habit — most objects in 3by5 have a context menu with useful options that don't have keyboard shortcuts yet.
