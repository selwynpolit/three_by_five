# Search and Filtering

3by5 has a few different ways to find things, each suited to a different situation. The quick guide: use ⌘K when you want to find anything fast, use the Task List search when you want to sort and filter in depth, and use the Kanban search when you're working through a board and need to focus.

---

## Global search (⌘K)

Press ⌘K from anywhere in the app and a search overlay drops down. Start typing and results appear immediately — you don't have to finish a word. Type "pro" and you'll see anything with "project" in it.

The search looks across task titles, task descriptions, note bodies, and card project titles all at once, using full-text search under the hood. Up to 12 matching tasks and 6 matching cards are shown, each in their own section so you can see at a glance whether you found a task or a card.

Navigate results with the arrow keys and press Enter to open the selected item. Press ESC to close the overlay without navigating anywhere.

This is the fastest path to any piece of information in your system. If you've used ⌘K in other apps (Spotlight, Raycast, Linear), you'll feel right at home.

---

## Task List search

Switch to Card View (⌘1), then click the rightmost icon at the top left to open the Task List. There's a search bar at the top of the table.

Typing here filters the visible rows in real-time by task title or card project title. It's a local filter — you're narrowing down what you see, not jumping to a result. This makes it useful when you want to combine searching with sorting.

For example: search for a tag name or a project, then click the Due Date column header to see everything related to that topic sorted by when it's due. Or search for nothing and just sort the Priority column to pull all your high-priority tasks to the top.

Press ESC to clear the search field and see all tasks again.

The "Hidden" toggle in the card view header also affects what the Task List shows. When it's on, tasks from hidden and snoozed cards appear in the table alongside everything else — useful if you're doing a full review and want to see the whole picture.

---

## Kanban search

The Kanban view (⌘2) has its own search bar in the header. Type to filter task cards by title or card name — everything that doesn't match fades away, so you can focus on a specific project or topic across all your workflow stages.

The "Hide completed" toggle works alongside the search. Turn them both on to see only the incomplete tasks relevant to your current focus.

---

## Filtering by tag or priority

There's no dedicated tag filter or priority filter panel yet — but you can get a lot of mileage out of the Task List view's sorting.

Click the **Tag** column header to group all tasks by tag together. Click the **Priority** dot column header to bubble up your high-priority tasks. Combine a sort with the search bar to narrow things down further.

## A few search patterns worth knowing

- **Looking for a task you remember vaguely?** ⌘K and type a word you remember from the title or description. Results show up fast.
- **Preparing for a weekly review?** Open the Task List, clear the search, and sort by Due Date. You'll see everything coming up in order.
- **Focused on one project?** Type the card/project name into the Task List search bar. Every task from that project surfaces immediately.
- **Working through your board?** Kanban search + "Hide completed" is a clean combo for a focused work session.
